Chính Sách Bàn Giao

Quy trình và cam kết bàn giao sản phẩm tại CodeMarket

Cam kết: Bàn giao đúng hạn 100% source code và tài liệu kèm theo

1. Thời Gian Bàn Giao

Loại sản phẩm Thời gian bàn giao Hình thức
Source code có sẵn Ngay sau khi nhận cọc sau đó giao source rồi thanh toán phần còn lại Gửi source qua zalo hoặc facebook
Dự án tùy chỉnh Theo thỏa thuận (theo deadline của khách hàng) Gặp mặt hoặc qua UtraViewer/TeamViewer/Zoom
Báo cáo/Bài luận Theo deadline hoặc yêu cầu khách hàng File Word/PDF + Giải thích

2. Quy Trình Bàn Giao

1
Xác nhận đơn hàng

Gửi thông tin qua zalo, facebook hoặc gmail và hướng dẫn thanh toán trong vòng 2 giờ làm việc

2
Chuẩn bị bàn giao

Kiểm tra chất lượng source code, viết tài liệu hướng dẫn và demo

3
Bàn giao chính thức

Gửi đầy đủ qua zalo, facebook hay hẹn meeting demo sản phẩm

4
Hỗ trợ sau bàn giao

Hỗ trợ cài đặt và giải đáp thắc mắc trong 7 ngày

3. Nội Dung Bàn Giao

Source code
  • File nén đầy đủ (.zip/.rar)
  • Code đã được kiểm thử
  • Comment rõ ràng trong code
Tài liệu kèm theo
  • Hướng dẫn cài đặt chi tiết
  • Sơ đồ CSDL (nếu có)
  • Tài liệu API (nếu có)

4. Trường Hợp Chậm Bàn Giao

Bồi thường theo hợp đồng

Nếu chậm hơn 3 ngày so với cam kết:

  • Giảm 10% giá trị đơn hàng cho mỗi ngày chậm
  • Hoặc hoàn tiền 100% nếu khách hàng yêu cầu

5. Câu Hỏi Thường Gặp

Thanh toán qua chuyển khoản ngân hàng hoặc ví điện tử để nhận source code nhanh nhất. Thanh toán trực tiếp có thể mất thời gian gặp trực tiếp.

  1. Kiểm tra tính đầy đủ của file nhận được
  2. Chạy thử trên môi trường local
  3. Đối chiếu với các tính năng đã yêu cầu
  4. Xem lại tài liệu hướng dẫn

Chúng tôi hỗ trợ:
  • Hướng dẫn cài đặt và triển khai
  • Giải thích code và logic chương trình
  • Fix các lỗi phát sinh do phía chúng tôi
  • Tư vấn nâng cấp (có thể phát sinh phí)
